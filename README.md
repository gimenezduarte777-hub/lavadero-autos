Lavadero de Autos

Sistema web para registrar turnos de lavado: vehículos, clientes y servicios.
Permite agregar, listar, editar y eliminar turnos, y cambiar su estado.

Tecnologías: HTML, CSS, JavaScript, Supabase, GitHub, Render y Google AI Studio.

Cómo ejecutarlo:
1. Crear un proyecto en Supabase y ejecutar el script SQL de las tablas vehiculos, servicios y turnos.
2. Copiar la Project URL y la clave anon public en app.js.
3. Abrir index.html en el navegador.

Publicación: (link de Render, lo agregamos después)

Limitación: las políticas de Supabase permiten acceso sin login. Se hizo así solo para el examen.
